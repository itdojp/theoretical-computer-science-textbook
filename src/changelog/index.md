# 更新履歴（CHANGELOG）

Web版はmainブランチから継続公開し、版番号を固定したPDF/EPUBは`v1.2.0` tagのRelease完了後に提供します。ここではコミット列挙ではなく、読者へ影響する変更を版ごとに整理します。

## Unreleased

- 現在、次版向けとして確定した読者向け変更はありません。

## 1.2.0 — 2026-07-16

### 読み始め方と再参照性

- 第一読者・前提知識・非対象読者をfront matterに明示し、通読、講義補助、拾い読み、再学習の入口を整理しました。
- Part opener、章プロフィール、章末ガイド、付録のクイックナビ、図版ガイド、概念マップ入口を追加し、章間の戻り先を増やしました。
- 通し例「安全なメッセージ配送基盤」を各Partへ接続し、抽象概念を同じ業務対象へ再投影できるようにしました。
- 機械換算の本文閲覧時間と、主要証明・代表問題を含む標準学習時間を分離し、12章の学習負荷を単一正本から表示するようにしました。

### 技術内容の監査と訂正

- 全12章を横断監査し、計算モデル、計算可能性・複雑性、形式言語、償却解析、グラフ条件、論理・モデル検査、情報理論、暗号、分散計算の前提と主張範囲を明確化しました。
- Turing機械の計算量モデル、ε-NFA除去、work-efficient parallel prefix、通信路符号の誤り指数、暗号学的security gameを形式化・訂正しました。
- 漸化式ごとに適用可能な解析法を整理し、Master theoremの適用外ケースとmax-flowのprimal/dualを補完しました。

### 付録・用語・相互参照

- 付録Cと章末問題の整合、用語の章横断整合、数学記法、用語集、図版索引、学習チェックリストを監査・拡充しました。
- Myhill–Nerode、Turing機械、冪集合、Kleene star、矢印・不等号、確率・情報理論の記法を統一し、Webとオフライン版で参照できる形へ整えました。

### 表示・ビルド・品質保証

- モバイルsidebarの重なりと表示条件を修正し、全公開ページのnavigation coverageを検査するようにしました。
- notation、生成索引、HTML、リンク、docs禁止物、依存監査、Jekyll buildをCIで継続検査し、品質ゲート自体の配線も検証するようにしました。
- 書名、版、著者、更新日、Release tagをcanonical metadataへ統合し、公式PDF/EPUBを安全に公開するRelease契約を整備しました。
