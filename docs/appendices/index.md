# 付録

本書の学習をサポートする補助資料を提供します。

## 使い分けの目安

- 定義や記号で止まったときは **付録A**、練習問題の回収は **付録C**、用語の再確認は **付録D** を入口にしてください。
- 実装の形で挙動を確かめたいときは **付録B**、理論が実システムでどう現れるかを見たいときは **付録E**、学習到達度を確認したいときは **付録F** を使います。
- 図を後から探し直したいときや、図ラベルの意味を確認したいときは **付録H** を使います。
- Web 以外の読み方や、公式 PDF / EPUB の提供状況を確認したいときは [オフライン版（PDF/EPUB）]({{ '/downloads/' | relative_url }}) を参照してください。
